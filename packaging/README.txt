Swell Realistic Guitar 1.0.0
============================

Application autonome et instrument VST3 (macOS 12+ Apple Silicon et Intel, Windows 10/11 64 bits).

1. Installation
   macOS   : le plugin va dans /Library/Audio/Plug-Ins/VST3.
             Si macOS bloque l'ouverture : clic droit > Ouvrir, ou
             Reglages Systeme > Confidentialite et securite > Ouvrir quand meme.
   Windows : le plugin va dans C:\Program Files\Common Files\VST3.

             Sur Mac, l’application est dans Applications et le format AU dans Components.
             Sur Windows, lance l’application depuis le menu Démarrer.

2. Activation
   Ouvre le plugin dans ton logiciel de musique, colle ta cle SWELL-XXXXX-XXXXX-XXXXX-XXXXX
   (visible dans ton espace sur swell-audio.fr) puis clique sur Activer.
   Internet est necessaire une seule fois.

3. Echantillons
   Les sons ne sont pas inclus. Clique sur l'icone dossier en haut a droite du plugin
   et choisis le dossier qui contient AG, NG, LP et TC. Le chemin est enregistre.
